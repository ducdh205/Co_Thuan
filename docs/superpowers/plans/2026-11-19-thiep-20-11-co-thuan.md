# Thiệp 20/11 tặng cô Thuận — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static website in `e:\CoThuan` that plays a ~95-second low-poly three.js "film" (paper boat, lighthouse, knowledge lights, island C, storm→rainbow, system city) in the "Bình minh rực rỡ" palette and ends on a 20/11 card for cô Thuận from Thu Phương.

**Architecture:** No build step. `index.html` loads ES modules through an import map (with `es-module-shims` polyfill) from jsDelivr. Each world element is a module exporting a `create*()` factory that returns `{ group, ...animatable handles }`; `js/film.js` composes one GSAP master timeline over those handles plus the HTML caption/card overlays. Pure logic (scene timing, quality tiers, URL debug params) lives in small modules tested with `node --test`; visuals are verified with headless-Chrome screenshots at seek times.

**Tech Stack:** HTML/CSS/JS ES modules · three@0.160.0 · gsap@3.12.5 · es-module-shims@1.10.0 · Google Fonts (Be Vietnam Pro, Dancing Script) · Web Audio API · Node 26 (`node --test`, tiny static server) · Chrome headless for screenshots.

**Spec:** `docs/superpowers/specs/2026-11-19-thiep-20-11-co-thuan-design.md`

## Global Constraints

- All user-visible text in Vietnamese with correct diacritics; draw canvas text only after `document.fonts.load()` resolves.
- Palette (exact): sky `#ff9a8b` → `#ffc3a0` → `#ffe29f`; sea `#4fd1c5` → `#2bb3c0`; accents pink `#ff5c8a`, purple `#7b61ff`, sun yellow `#ffd166`, white `#ffffff`. Never a dark/gloomy look; the storm is short and grey, not black.
- Pinned CDN versions only: `three@0.160.0`, `gsap@3.12.5`, `es-module-shims@1.10.0`. No npm dependencies in the shipped site.
- All asset/script paths relative (no leading `/`) — site must work from a GitHub Pages sub-path.
- Geometry only from three.js built-ins (`flatShading: true`); no external model files.
- Total film ≈ 95 s (1.5–2 min). Code appears only as small accents (`Hello, World!` on the sail, error words in lightning, `return 0; // cảm ơn cô` on the card) — never a code-editor screen.
- `devicePixelRatio` capped at 2; works on portrait phones (≥360 px wide) and landscape laptops.
- Card copy is fixed and verbatim (see Task 2). Captions verbatim (see Task 1).
- Commit after every task; message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Opened inside Zalo/Messenger or a phone without WebGL** → the 2D fallback card shows the same card text and palette; never a white screen. (Task 2 screenshot `?nowebgl=1`.)
2. **CDN slow or blocked** → loading screen gives way to the 2D fallback after 12 s instead of spinning forever. (Task 2 screenshot `?forcefail=1`.)
3. **Portrait phone 390×844** → boat, lighthouse, captions and the whole card stay inside the frame; long card text scrolls inside the card, never clipped. (Task 8 screenshots.)
4. **"Xem lại" pressed, or tab hidden mid-film** → film restarts cleanly with no duplicated objects or doubled music; hiding the tab pauses film and music, returning resumes. (Task 7 test + manual check.)
5. **Vietnamese diacritics on canvas textures** (sail, building sign) render correctly, not fallback-font tofu. (Task 4/6 screenshots.)

```
tools/serve.mjs         zero-dependency static server (node tools/serve.mjs [port])
tools/shoot.mjs         headless Chrome screenshots: node tools/shoot.mjs <query> <WxH> <out.png>
tests/*.test.mjs        node --test unit/static tests
assets/og.png           link-preview image (generated in Task 8)
README.md               how to run locally, add music, publish on GitHub Pages
```

Debug URL params (used by tests and screenshots): `?t=<seconds>` seek film and freeze; `?autostart=1` skip the "Mở quà" button; `?nowebgl=1` force fallback; `?forcefail=1` simulate CDN failure; `?quality=low|high` force tier.
